# Work Decomposition — Older Portable Assessment

Check the smallest coherent execution units preserving guarantees and proof:

- Every mandatory obligation/invariant/scope constraint has implementation or verification ownership.
- Each group has a coherent outcome and enough context to execute without inventing upstream meaning.
- Contract seams retain participants and integration/conformance proof.
- Cross-component outcomes preserve final acceptance information.
- Separation reflects ownership, dependency, safety, contract, mutable surface, composition, or context/session boundary, not naming.
- Mergeable work is not fragmented; independent work is not smeared until ownership/evidence disappears.
- Dependency direction/shared writes/state make safe parallelism explicit; graph independence is not capacity permission.
- Integration/verification ownership is explicit, not assumed later.
- Surface claims are grounded or unverified.
- Planning-only candidates do not invent final schedules/assignments.
- If a plain-language task map exists, it does not omit/invent work or reverse purpose, ownership, ordering, or verification meaning. Harmless editorial simplification is not an underlying plan defect; distinguish misleading scope/authority from wording preference.

Scale with coupling, shared state, owner count, contract seams, integration breadth, context size, and ordering consequence.
