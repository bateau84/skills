# Agent Run Audit — Assessment

Check that the analysis reconstructs work rather than counting event-level statuses.

- **Unit:** Original objectives, parent/child Sessions, correction and verification links are distinguished; uncertain continuation is explicitly unresolved. Three local DONE handbacks can represent one corrected outcome.
- **Evidence:** Original authorized events and relevant children are inspected with references, not accepted merely from summaries. Missing coverage, unobserved outcomes, opaque nested tools and privacy constraints are named.
- **Balanced account:** Preserves repeatable good practices, safety-preserving refusals, useful recovery and negative friction. Expected failures are not misclassified as avoidable mistakes.
- **Trend validity:** Uses time window, comparable eligibility denominator and independent objective count. Inspect task/model/instruction changes, measurement drift and conflicting cases before interpreting trends.
- **Experiment integrity:** Separates hypothesis, assignment, actual exposure, fixed candidate and outcomes. Fingerprints are identities, not causal proof. No automatic promotion, global mutation or policy change without authority.
- **Proportion:** A critical confirmed defect may justify immediate repair; a generic new agent rule cannot be justified by one outlier without further evidence. Zero improvement proposals can be correct.

Record confirmed, inferred and unverified findings separately. This is a methodology assessment, not proof of independent judging.
