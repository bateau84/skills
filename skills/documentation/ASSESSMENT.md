# Documentation Assessment

Independently review truthful documentation of observed behavior and publication guidance. Product authority and OKF representation checks are separate concerns.

## Review criteria

- Current-reality claims are supported by observed implementation, tests or credible direct evidence.
- Planned behavior and accepted requirements are not presented as already implemented.
- Changed facts are updated while unaffected documents are not rewritten for symmetry.
- System overviews remain concise while covering important components, flows, states, public boundaries and operations.
- User-facing instructions match supported commands and behavior, with meaningful prerequisites and failure handling.
- Conflicts between implementation and accepted intent are reported rather than hidden.
- Examples and compatibility claims were verified to the extent claimed; limitations are explicit.
- When OKF representation is in scope, invoke the independent `okf-authoring` assessment instead of treating a valid index as proof that the content is true.

## Review depth

Scale with impact of misinformation, audience and operational consequences.
